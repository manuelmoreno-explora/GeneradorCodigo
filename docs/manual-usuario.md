# Manual de uso — Radicación de correspondencia TYC

Para: personal de Gestión Documental. Ingresa con tu cuenta corporativa (`@parqueexplora.org`).

## Radicar un documento (recibido o enviado)
1. Entra a **Nueva operación**.
2. **Paso 1:** elige **Recepción** (correspondencia recibida) o **Entrega** (correspondencia enviada).
3. **Paso 2:** arrastra el PDF o pulsa "elige un archivo". Un solo PDF, máximo 10 MB.
4. **Paso 3:** revisa el resumen y pulsa **Generar código y archivar**. Espera unos segundos; no cierres la ventana.
5. Verás el **código** (por ejemplo `26-001`). El PDF ya quedó en Drive con el código estampado arriba a la derecha y con el nombre `TYC-Correspondencia recibida 26-001` (o `enviada`).
6. Si la correspondencia se entrega, pulsa **Imprimir ejemplar de entrega** (o **Descargar PDF**). Si está habilitado, también **Enviar por correo**: escribe el correo de quien recibe el documento y pulsa Enviar; sale desde tu cuenta con el PDF adjunto (revisa bien la dirección, no se puede deshacer). Es el mismo PDF con el mismo código; **no se guarda aparte**: en Drive hay un solo PDF por radicado.

## Si algo falla
Aparece "No se pudo completar" y el mensaje dice la causa (por ejemplo, PDF dañado o con contraseña). **No se consumió ningún código**: la secuencia no cambia. Corrige el archivo y vuelve a intentar. Si el mensaje dice que el proceso tarda más de lo normal, **no reintentes**: avisa a quien administra la herramienta (revisará el Panel).

## Buscar un radicado
En **Buscar** filtra por código (completo o parcial), tipo, estado o fechas. "Abrir" lleva al PDF en Drive. Estados: *Completada* (archivada), *Anulada* (anulación autorizada; el número no se reutiliza), *En proceso* (aún se está generando).

## Panel
Muestra el último consecutivo del año y los totales. **Validar ahora** comprueba que no falte ni se repita ningún número; en verde (✔) todo está bien. Si sale rojo (✖) indica los consecutivos faltantes o duplicados: avisa a TI. **Exportar registro (CSV)** descarga todos los radicados para abrirlos en Excel. Cada día a las 7 a. m. se valida automáticamente.

## Excepciones (solo personas autorizadas)
Si no ves el menú **Excepciones**, no tienes autorización; pídela a Gestión Documental.
- **Registrar observación:** deja constancia de una inconsistencia sin cambiar el radicado.
- **Anular el radicado:** para un documento ya archivado que debe anularse. Indica código, descripción, acción correctiva y quién autoriza, y marca la casilla de confirmación. El código **no se reutiliza** y el archivo de Drive **no se borra**.

## Reglas que no cambian
- **Recibida y enviada llevan numeración independiente.** Puede existir una recibida 26-135 y una enviada 26-135; se distinguen por el nombre del archivo y la carpeta.
- Cada documento tiene su propio código; el código aparece en el PDF y en el nombre del archivo.
- No se renombran ni se mueven manualmente los archivos de las carpetas TYC. No se edita el Sheet a mano.
- Un código solo existe si el archivo quedó en Drive.
